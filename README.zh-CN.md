# 元核生物 · Yuanhe Bio

**面向分子发现的计算证据与候选决策工作台。**

[English](README.md) · [产品说明](docs/PRODUCT.md) · [访问与发布边界](docs/ACCESS.md)

元核生物将分子设计、虚拟筛选、分子风险评估与分子动力学准备连接到统一研究工作台，帮助研究人员整理计算证据，确定值得进一步研究的候选分子。

## 产品流程

研究目标与输入准备 → 候选分子探索 → 筛选及风险审查 → 模拟准备与分析 → 证据导出与实验规划。

| 能力 | 面向研究人员的用途 |
|---|---|
| 分子设计 | 探索候选分子并保留分子身份与来源 |
| 虚拟筛选 | 根据可审阅证据对候选进行优先排序 |
| 毒性与可合成性评估 | 提供计算风险提示和可行性证据，供专家复核 |
| 膜环境准备 | 审查膜环境并准备后续模拟体系 |
| 分子动力学 | 组织模拟、分析及过程记录 |
| 统一工作台 | 管理输入、任务状态、人工审查和结果导出 |

## 当前阶段

产品处于研究开发阶段。实际可用能力取决于计算环境、模型与数据授权以及靶点验证。计算分数不等于实验活性，风险评估不等于毒理安全认证，合成可行性预测不保证实验合成成功。这里不承诺临床效果、命中率提升或生产服务等级。
